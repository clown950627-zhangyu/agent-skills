## 精确参数（从参考视频实测提取）

| 参数 | 值 |
|------|-----|
| 中文字号 | 44px @720宽（参考视频：34-43px @720x960） |
| 中文字体 | NotoSerifCJK-Regular（细衬线·**不加粗**） |
| 中文字距 | 4px |
| 中文颜色 | 纯白 (255,255,255) alpha 222 |
| 英文字号 | 16px |
| 英文字体 | DejaVuSans（无衬线）·**全部小写** |
| 英文颜色 | (245,245,245) alpha 205 |
| 中英行距 | 16px |
| **字幕位置** | **y = 0.50H（垂直居中偏上·不是底部）** |
| 柔光晕染 | GaussianBlur(9px)·黑色 alpha 90 |
| 描边 | **无** |
| 暗底条 | **无** |
| 淡入淡出 | 0.5秒 |

## 参考视频画面特征

- 主调：青绿+暖橙双色渐变（Teal #4DB8C9 → Peach #F7B731）
- 运镜：平稳（无人机/稳定器感）
- 节奏：每屏1句·2-3秒·留白多·不抢画面
- 首帧标题字号略大（5%H）作为片头
